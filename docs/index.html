01 / THE SUPPLIED LOGIC

Some clauses can change.
The background cannot.

A clause is an OR of literals. The formula is an AND of clauses. An empty clause is false. Empty clause lists are true. Literal repetitions normalize within a clause; duplicate clause identities remain separate. A cost is a supplied preference for removal, not a fault probability.

05 / WHAT THIS DOES NOT ESTABLISH
Consistency is not truth.
Removing supplied constraints restores a logical model. It does not establish which physical component failed, which observation is wrong, or which real action is safe. Costs are editable positive preferences, not probabilities. The hard background is an assumption, not verified knowledge.
All 2m soft subsets and 2n truth assignments are enumerated. This is an exhaustive tiny inspector using established MUS/MCS duality and DPLL, without clause learning, industrial benchmarks, learned diagnosis or a scalable algorithm claim. Traces are inspectable computational witnesses, not DRAT/LRAT exports or machine-checked proofs.
